### Project Description
An autonomous robot that detects humans and immediately tries to escape from them. It uses a camera, distance sensors, and motors to maintain its personal space because apparently, even robots need boundaries.

### The Problem (that doesn't exist)
Humans keep approaching robots without permission. This creates an extremely serious problem: the robot may have to interact with people.

### The Solution (that nobody asked for)
We built an Anti-Social Robot that detects approaching humans and runs away from them. It displays increasingly desperate messages such as "HELLO HUMAN", "BACK OFF!", and "WHY ARE YOU FOLLOWING ME?" while navigating around obstacles.

## Technical Details
### Technologies/Components Used
#### For Software:
- **Languages:** C/C++ (Arduino)
- **Framework:** Arduino Framework
- **Libraries:** ESP32 Camera Library, Wire, Adafruit GFX, Adafruit SSD1306
- **Tools:** Arduino IDE, Wokwi, Serial Monitor

#### For Hardware:
- ESP32 / ESP32-CAM
- Camera Module
- 2 × HC-SR04 Ultrasonic Sensors
- L298N Motor Driver
- 2 × BO Gear Motors
- 2 × Wheels
- 1 × Caster Wheel
- 0.96" OLED Display
- Battery Pack
- Jumper Wires
- Robot Chassis
- Breadboard
- USB Cable

# Installation

Install:
- Arduino IDE
- ESP32 Board Package
- Required ESP32 Camera libraries
- Adafruit GFX Library
- Adafruit SSD1306 Library

For Wokwi simulation, add the required libraries through the Library Manager.

# Run

1. Connect the ESP32/ESP32-CAM to the computer.
2. Select the correct ESP32 board and COM port.
3. Upload the program.
4. Power the robot.
5. Approach the robot.
6. Watch it panic and run away.
